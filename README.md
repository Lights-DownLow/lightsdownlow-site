# Lights Down Low

The public site for Lights Down Low, underground dance music in Los Angeles since 2006.

This folder is the built site and is published as it is. It is generated from a draft, so edits made here by hand are overwritten on the next update.

- `index.html`, `css/`, `js/`: the page
- `js/data.js`: shows and the flyer list
- `f/`: flyer images (`t` small, `l` large, `v` video)
